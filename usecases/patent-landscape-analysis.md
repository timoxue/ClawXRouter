# 专利地图与技术空白识别

R&D 团队做技术布局前需要看清楚专利地图：谁占了什么位置、哪些方向还有空间、怎么绕过现有壁垒。一个专利分析师做一份完整的技术白地图报告要 2-4 周。这个流程中，专利检索、元信息提取、权利要求分割都是高吞吐量的机械工作，但技术空白识别和规避设计需要真正的创造性推理。

Token-Saver 让小模型批量处理专利原文（每篇动辄几千字的权利要求书），大模型只在需要 "发现没人做过的方向" 和 "设计绕过方案" 时介入。

## Pain Point

- 一个技术领域可能有 500-5,000 件相关专利
- 每件专利的权利要求书平均 2,000-5,000 字，全文更长
- 元信息提取（申请人、IPC 分类、优先权日期、引用关系）是纯结构化工作
- 但 "这个领域还有哪些技术方向没人做" 需要跨专利的综合推理
- "怎么设计一个方案绕过这件专利" 需要创造性的技术思维
- 全量大模型处理 1,000 件专利：$200-500+

## Prompt 示例

### 完整专利地图分析

```text
帮我做一个 "固态电池" 技术领域的专利地图分析。

第一阶段 — 数据收集：
1. 检索范围：中国（CNIPA）+ 美国（USPTO）+ 欧洲（EPO）
2. IPC 分类：H01M 10/05xx (固态电解质)
3. 时间范围：2020-2026
4. 提取每件专利的：申请人、发明人、IPC 细分类、优先权日、法律状态、独立权利要求

第二阶段 — 分析：
5. 按技术路线聚类：
   - 硫化物电解质
   - 氧化物电解质
   - 聚合物电解质
   - 复合电解质
6. 每条路线的头部申请人 TOP 10 + 专利量趋势
7. 引用关系图谱：核心专利（被引 > 20 次）标注出来
8. 技术空白识别：哪些交叉方向还没有专利？

第三阶段 — 策略：
9. 如果我们想进入 "硫化物-聚合物复合电解质" 方向：
   - 需要绕过哪些关键专利？
   - 可行的技术规避路径是什么？
   - 建议的专利布局方案（布几件、各覆盖什么）

输出专利地图的可视化数据（JSON 格式，用于 ECharts 渲染）。
```

### 单件专利深度分析

```text
专利 CN2024100xxxxx 的独立权利要求覆盖范围很广。
帮我分析：
1. 这个独权的保护范围到底有多大？每个技术特征是必要的吗？
2. 有没有可能通过修改某个技术特征来规避？
3. 这个专利有没有无效的可能性？（查前引专利和公开日期）
```

### 竞争对手分析

```text
基于专利地图数据，对比以下公司在固态电池领域的布局：
- Toyota（丰田）
- Samsung SDI
- QuantumScape
- 宁德时代

分析维度：
1. 专利数量和增长趋势
2. 技术路线偏好
3. 核心专利（被引高的）
4. 最新申请方向（最近 1 年）
5. 各自的技术壁垒和弱点
```

## 关键洞察

- **权利要求书是 Token 大户**：一件专利的权利要求书 2,000-5,000 Token，1,000 件就是 2-5M Token。这些全用大模型解析就是烧钱
- **元信息提取几乎不需要推理**：申请人、日期、IPC 分类号都是结构化字段，小模型提取准确率 > 98%
- **聚类是中间环节**：把 1,000 件专利按技术路线分成 10-20 个聚类后，大模型只需要看每个聚类的摘要（而不是所有原文）来做空白识别
- **技术空白 = 排除法推理**：大模型需要理解 "什么已经有了" 然后推理 "什么还没有" — 这是创造性推理，小模型做不到
- **规避设计需要创造力**：给定一个权利要求，想出功能等价但特征不同的替代方案，这是 REASONING 级别任务
- **引用图谱揭示核心节点**：被引用次数最多的专利是 "基石专利"，它们的权利要求定义了整个领域的技术边界
